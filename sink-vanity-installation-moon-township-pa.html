What We Handle, and What Needs a Licensed Plumber

This service covers installing sinks and vanities using your home's existing supply lines and drain connections — the most common scenario for a bathroom or kitchen update. If your project involves moving plumbing to a new location, running new supply lines, or other work that requires a licensed plumber, we will tell you plainly before starting.

We check every connection for leaks before finishing the job, since a slow leak under a sink can go unnoticed for weeks and cause real damage.

Sink & Vanity FAQs

Do you install both bathroom vanities and kitchen sinks?

Yes, we handle both, along with the plumbing reconnection each requires.

Can you move my sink to a new location?

Relocating plumbing requires a licensed plumber. We install sinks and vanities using existing supply and drain locations.

Do you haul away the old vanity or sink?

Yes, we can remove and dispose of the old fixture when we install the new one.

Do you check for leaks after installing?

Yes, every install is checked by running water and inspecting all connections before we leave.
